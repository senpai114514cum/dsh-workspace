## 三、发现的一个真问题：正文段落被整段包进 `$$`

### 现象

抽查 `en-01`（纯数学论文）时发现"块公式"里有一段是**英文散文**：

```
$$\n, countable subadditivity yields indices $i \in \{ 1 , \ldots , n \}$ and $k \geq 1$ for which\n$$
```

量化后：

| 文件 | 块公式 | 其中是散文 | 占比 |
|---|---|---|---|
| en-01 纯数学 | 251 | **94** | **37%** |
| en-05 Shor | 49 | **39** | **80%** |
| 其余 9 篇 | — | 0 | **0%** |

### 为什么这是真问题（和"数字空格"不同）

数学模式忽略空格 —— 这一点**这次反而成了危害**：散文放进 `$$` 后，单词会**连成一坨**。

实测（ziamath 渲染对比）：

| 输入 | 渲染结果 |
|---|---|
| `countable subadditivity yields indices` | 与下一行**完全相同** |
| `countablesubadditivityyieldsindices` | 与上一行**完全相同** |
| `\text{countable subadditivity yields}`（对照） | 与不带空格的**不同** ✓ |

即渲染出来是 `countablesubadditivityyieldsindices` —— 而且是数学斜体。**这段正文变得不可读。**

> 对比之前那条"数字被空格拆开"：那个在数学模式里渲染完全正常，**只是源码不好看**；
> 这一条才是**真正影响阅读的缺陷**。

### 已修：检测 + 自动还原

* 新增体检规则：`$$` 块里（排除 `\text{}`/`\mathrm{}` 之后）有 4 个以上连续英文单词 → `warn`
* 自动清理会**去掉外层 `$$`**，把这些段落还原成正文，同时保留其中的行内公式

实测效果：

| 文件 | 修复前块公式 | 修复后 | 还原的段落 |
|---|---|---|---|
| en-01 | 251 | **157** | 94 |
| en-05 | 49 | **10** | 39 |

清理日志实际记录：
```
[WARN] 94/252 个块公式里其实是散文 —— 样例："countable subadditivity yields indices"
已清理：把 94 个误包成公式的段落还原成正文、整理公式 25 处
```

修复后全部 11 篇的"散文误包"计数归零，且体检问题 0 项。

## 四、顺带修掉我自己两个检查器 bug

排查这 11 篇时，体检报了 2 个 ERROR，**查下去又是我的问题**：

### ① YOLO 的"表格编造"是假的 —— 宽表被拆分成多个结构

```
原文表格标题: 1, 2, 3   （3 个）
输出表格:     5 个
```

看内容就清楚了：

```
1) | Real-Time Detectors | Train | mAP | FPS |   ← Table 1
2) | Less Than Real-Time |  |  |  |              ← Table 1 的后半段（宽表拆开）
3) |  | mAP | Combined | Gain |                  ← Table 2
```

**是宽表被拆成两段，不是编造。**

**处理**：把"表格数超出"从 `error` 降为 `warn`，并在说明里同时列出两种可能
（曲线图数字化 / 宽表拆分）。真编造仍然会被抓住 ——
因为它一定伴随 `~` 估算值，那条规则保持 `error`：

```
p2 advanced    体检：1 项严重、2 项警告
      error: ['表格里有 133 个 "~" 估算值']
      warn : ['表格数比原文多 5 个', '存在图像解读产物']
```

### ② Shor 的"表格编造"是假的 —— 分节编号没被识别

Shor 论文的表格标题是 **`Table 3.1` / `Table 3.2`**，我的正则 `Table\s*(\d+)`
把两个都截成 `3`，于是只数出 1 个标题。

**处理**：正则改为 `(\d+(?:\.\d+)*)`，保留小数部分 → 现在正确数出 2 个，
判定回到"一致"。

**回归验证**（9 个用例全过）：ResNet / Attention / IRS 表单 / 罗马数字论文 /
YOLO 宽表拆分 / Shor 分节编号 → 全部 info 或合理的 warn；
而 p2、p3 两个真编造样本仍然报 **1 项严重**。

## 五、结论

1. **公式转换质量非常高**：490 个块公式 100% 语法有效，2215 个行内公式 99.95% 有效。
   纯数学论文（en-01，1296 个数学符号）和高能理论（en-02，880 个符号）都能完整还原。

2. **唯一的公式类真缺陷是"散文被包进 `$$`"**，且集中在 2/11 篇（都是数学与正文高度
   交织的排版）。已实现检测 + 自动还原。

3. **中文论文表现与英文相当**：中国科学系列的 6 篇全部 OK，公式有效率 100%，
   图表抽取正常（cn-06 抽出 23 张图、cn-01 抽出 19 张）。

4. **图片抽取零缺失**：106 张图全部落成独立文件，md 里的引用全部有效。

5. **三个"错误"里有两个是我的检查器误报** —— 这已经是连续第四轮出现同样的模式。
   经验：**看到报警先质疑检查器，再质疑模型。**
